# Why do Navon letter preference and human shape agreement change?

The [letter notebook](navon_analysis.ipynb) reports that AligNet prefers the local match more strongly than UnAligNet in both families. The [shape experiment](navon-shapes.md) measures agreement with human visual-search speed. Its primary Spearman scores (Base, UnAligNet, AligNet) were .442, .330, .328 for DINOv2-B and .310, .419, .451 for SigLIP-B. The largest shape changes occur between Base and UnAligNet. A local preference on letters alone cannot explain the family difference.

Use all six official checkpoints. Pair comparisons on identical stimuli within each family. Report UnAligNet minus Base and AligNet minus UnAligNet separately. Use normalized pre_logits as primary and report triplet_logits separately because the Base projection head is untrained. Record preprocessing and retain the unresolved DINO preprocessing provenance. The experiments below are proposed follow-ups.

## 1. Identify which distances changed

Start with the matched substitution from notebook section 5. For each identity pair X,Y and context Z, measure the distance between C(X,Z) and C(Y,Z) (global change), then between C(Z,X) and C(Z,Y) (local change). Use 1 minus cosine for both. Their difference, global-change distance minus local-change distance, has the notebook's sign convention. Report both component distances and their paired changes across checkpoints. A more negative margin can arise from a smaller global-change distance, a larger local-change distance, or both. Show this for each size/spacing setting, then repeat across positions. For comparison A, show each raw cosine separately at each isolated-reference scale. Agreement confined to one reference scale would implicate the choice of reference.

Apply the same matched substitution to the 49 shapes. First recover the global and local identity of every image from the source metadata and verify the mapping against a labeled image gallery. For humans use the saved reciprocal mean reaction time as distance. Compare the sign and rank of matched substitution effects across identities for humans and each checkpoint. Keep human and model units separate. Also compute model–human Spearman on pairs changing only global identity, only local identity, and both. Differences within these groups and differences between their typical distances can both change the overall correlation. Show group counts and distributions. A stable global/local preference alongside a large change in within-group ranking would motivate examining which individual shape substitutions became more or less distinguishable.

Keep measurements paired across variants. Assess sensitivity to omitting each shape identity in both roles and to omitting each participant when recomputing human distances. On letters, repeat the summary omitting each glyph in all roles, including its role as the replacement. Comparisons share stimuli. Report the spread of these sensitivity checks as descriptive, alongside the full-data estimates.

## 2. Test whether global and local identity remain readable

Train separate regularized linear classifiers for global and local identity on frozen compound embeddings from each dataset. To predict global identity, hold out the local identity as a group. To predict local identity, reverse the roles. Keep all renderings of a held-out context together. Score the same eligible examples for every checkpoint, report macro accuracy and confusion matrices, and flag absent classes or missing combinations. Balance context frequencies, use the same penalty grid with context-disjoint inner validation, and include a context-only classifier to quantify predictability caused by missing combinations. Report held-out-context scores individually, especially for the seven shape contexts.

Compare each probe with experiment 1. If global decoding stays high while global-change distances shrink, global identity remains accessible even as it contributes less to the measured distances. A selective drop in global decoding would support reduced linear accessibility. Near-perfect probe accuracies may hide changes in geometry. Use distance measurements to interpret such ties. The Base feature reweighting in run 7167305 offers a further check: use its saved out-of-fold predictions to ask which pair types gained agreement, comparing identical test pairs before and after adaptation and reporting sparse strata.

## 3. Separate local size from spacing

The notebook jointly varies glyph size and spacing. Render a crossed grid using at least two legible element sizes and two spacings at each size. Fix font, outline, position and rotation. Use the same identity substitutions in every cell. Audit clipping, occupied area, element count and whether the outlines remain recognizable after preprocessing. Include an unfamiliar font as a transfer check. Plot paired changes in each component distance from experiment 1 when size alone changes and when spacing alone changes. A spacing effect at fixed glyph size implicates arrangement or density. A size effect at fixed spacing implicates element visibility or ink coverage. Neither manipulation alone isolates spatial frequency.

## 4. Locate an effect inside the model

Pursue this after finding a reproducible cue-specific change. Confirm the exact official checkpoint exposes usable intermediate activations and that a split forward pass reproduces its original embeddings. Repeat the probes across layers first. Then, within each checkpoint, choose donor and recipient images with the same global shape but different local shapes. Transfer selected intermediate token activations from donor to recipient, finish the forward pass, and score similarity to independent examples carrying either local identity. Repeat with the global and local roles reversed. Match the number and positions of transferred tokens across cue conditions. Compare with self-transfer and donors unrelated to the tested identity. A transfer that moves the output selectively toward the donor's identity would implicate that layer and token set under the intervention. Use fresh images to confirm layers selected during exploration.

This adapts the activation-transfer idea from [Patchscopes](https://arxiv.org/abs/2401.06102) to a vision encoder. The [AligNet study](https://www.nature.com/articles/s41586-025-09631-6) motivates evaluating transfer from object similarity judgments to visual search. Human agreement on the synthetic letters would require behavioral measurements on those letters with the reference scales and comparison task specified.
